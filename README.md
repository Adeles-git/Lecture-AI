## Что умеет прототип (КТ 3 — Основной сценарий)

1. **Загрузка всех материалов преподавателя + Live-субтитры на лекции:**
   - Загрузка реальных файлов курса (`.pptx`, `.docx`, `.pdf`, `.txt`, `.md`, `.csv`) с автоматическим извлечением текста и структуры.
   - Режим **«На лекции»** — потоковое распознавание речи (`Web Speech API` + индикатор `Silero VAD`) с автокоррекцией профильных терминов по силлабусу курса.
   - Встроенные вузовские пакеты для проверки в 1 клик (**КазГАСА: Архитектура и сейсмика**, **Основы ИИ и RAG**, **AlmaU: Бизнес и юнит-экономика**).
2. **Адаптированный конспект на «Ясном языке» + Всплывающие карточки терминов:**
   - Двухуровневый режим («Ясный язык» рядом с оригинальным академическим текстом для экзамена, по запросу 100% опрошенных студентов).
   - Кликабельные термины в тексте открывают всплывающую карточку с простым объяснением, научным определением и примером.
   - **Скачивание конспекта и глоссария** в `.DOC` / `.PDF`.
3. **Интерактивная структурная Майнд-карта (Mind Map):**
   - Векторный граф связей темы с кликабельными узлами и **скачиванием в `.PNG` и `.SVG`**.
4. **Мини-тест из 5 вопросов для самопроверки:**
   - Автоматическая проверка ответов, подсчёт баллов, разбор ошибок на «ясном языке» и **скачивание теста с ключами (`.DOC`)**.
5. **Code-Driven 2D Видео-Анимация (Мультфильм по лекции) + Контролирующая модель AI Supervisor:**
   - 3-эшелонный контур **AI Supervisor / Critic** проверяет факты по силлабусу (RAG), темп субтитров ($\le 15$ симв/с), контраст `WCAG AAA (15.4:1)` и отсутствие наложения блоков (`0 px²`).
   - 2D-видеоплеер (60 FPS) с анимированным персонажем-тьютором, динамическими схемами и 2-секундными визуальными паузами для чтения.
   - **Скачивание готового видеофайла (`.WEBM` / `.MP4`)** прямо в браузере (через `Canvas.captureStream` + `MediaRecorder` без платного сервера) и файла субтитров (`.SRT`).
6. **Гибридная монетизация и журнал кредитов (`Append-Only Credit Ledger`):**
   - Тариф `Free (0 ₸)` со всеми функциями через лимиты, демо-пополнение **100 ₸ за генерацию (пакет 500 ₸ за 5 лекций через Kaspi QR)** и льготный доступ **0 ₸ для студентов с нарушением слуха**.

## Быстрый запуск (Инструкция для преподавателя и команды)

### Вариант 1 — Мгновенный запуск на компьютере (0 установок)
Откройте файл `index.html` в любом браузере (Chrome, Edge, Safari) **или** запустите встроенный Python-сервер одной командой в терминале:

```bash
python3 server.py
```

После запуска откройте в браузере: **http://localhost:8080**

### Вариант 2 — Бесплатная публикация в интернет по публичной ссылке ($0, без банковской карты)
1. Загрузите эту папку в репозиторий на **GitHub**.
2. Зайдите на [vercel.com](https://vercel.com) (вход через GitHub, карта не нужна) → **Add New Project** → выберите репозиторий → нажмите **Deploy**.
3. Через 15 секунд вы получите постоянную публичную ссылку вида `https://lecture-ai-archai.vercel.app`, которая работает 24/7 с любого телефона и ноутбука до конца сессии.
